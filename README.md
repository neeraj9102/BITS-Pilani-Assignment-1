# BITS Pilani Assignment 1

This repository contains both compulsory applications for the assignment:

- [Part 1A — Smart Todo](Part-1A/README.md): deterministic local task CLI with an independent four-gate harness.
- [Part 1B — Natural Language Reminder Agent](Part-1B/README.md): provider-configurable proposal agent with a local Ollama path and an 18-case layered evaluation harness.

Each part has its own GitHub Spec Kit project, constitution, reviewed specification, clarifications, plan, tasks, contracts, tests, quickstart, and evidence directory. Start with the per-part README and quickstart. Part 1B supports local Ollama inference without an API key and retains an optional OpenAI adapter. The fixed 18-case local evaluation has a captured PASS; review the per-case raw model and guarded application outputs. Never commit credentials.

The repository preserves machine-generated test/evaluation evidence and source snapshots. The student must complete narrative harness-log entries, final human acceptance decisions, and the assessed reflection responses.
